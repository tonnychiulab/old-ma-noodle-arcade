## 瀏覽器操作檢查

- 本機瀏覽器視窗顯示正式分頁標題與 favicon；首頁可見相同完整遊戲名稱、`v0.1.0`、共同作者及模型揭露，並列出 30 款遊戲圖示。
- 開始「夜市快手」後顯示遊戲畫面和三個對應觸控操作；遊戲回傳分數。
- 首次進入「氣球射手」時按需載入該遊戲素材，載入層完成後收起，並顯示該模式五個觸控操作。
- 手機尺寸畫面依序啟動並返回其餘 24 款遊戲；每款都顯示自己的目標提示與相符的觸控操作，瀏覽器主控台沒有錯誤。
- 手機畫面抽查「夜市快手」「夜市拼圖」「招牌消消樂」「老馬大冒險」：操作提示以畫布外大字顯示，場景可見紅白棚布、街屋窗燈、電線與磁磚路面。招牌消消樂按一次交換即湊出三連並加分。
- 使用兩個瀏覽器頁面完成房主建立房間、朋友以代碼加入、雙方準備、房主開始，以及操作後雙方排行榜同步顯示分數。
- 瀏覽器檢查顯示每款使用可辨認的攤位/街巷構圖，食物、遊戲攤、廟口、雨巷和屋頂場景依遊戲不同呈現。命中特效（火花、分數彈跳、低幅鏡頭震動）已實作；本輪未逐款人工評估操作手感的平衡度，且特效會尊重系統的減少動態效果設定。
- 本次再次以本機瀏覽器確認首頁 Loading 收起後不建立遊戲 canvas；首次按「開始夜市快手」才載入 Phaser 並成功顯示畫布、遊戲提示與觸控操作。

## 尚未涵蓋的發佈前驗收

GitHub Pages 靜態網站已部署；多人房間伺服器仍僅供本機執行，未公開部署。本報告不宣稱已在實體 iOS/Android 裝置或多種主流瀏覽器完成相容性矩陣測試。20 秒斷線重連、逾時退賽、多人房間實際房主移交、第五位玩家拒絕及 40 秒完整多人回合仍需在多人伺服器部署環境做發佈前驗收。房主移交的在線玩家選舉已有單元測試，但未做真實斷線整合測試。
